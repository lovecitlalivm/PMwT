# PMWT

一个账号密码网址管理器，用来记录那些零碎的账号密码，防止丢失和遗忘。

## 简介

日常上网注册的账号越来越多，网址来往复杂，密码要么记不住、要么为了安全设得太复杂反而自己也想不起来。PMWT 就是为了解决这个问题：把零散的账号、密码、网址集中记录下来，需要时能快速找到、直接复制使用。

> **当前状态**：开发进度较少，功能比较简陋，暂时还比不上同类成熟软件。道阻且长，但会持续迭代。

## 特性

- **搜索**：按关键词快速查找已保存的账号、网址记录，不用一个个翻。
- **一键复制**：找到记录后直接复制账号或密码，省去手动选中、复制的麻烦。

## 面向人群

适合账号密码繁多、网址来往复杂、经常忘记密码或网址的人。

## 环境要求

- Python 3.x
