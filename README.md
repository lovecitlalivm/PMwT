# PMWT

> 一个账号密码网址管理器，记录那些零碎的账号密码，防止丢失和遗忘。
> 
## 📖 简介

你是否也遇到过这些情况：

- 🤔 注册过的网站太多，账号密码记不清了
- 😵 生成的复杂密码根本记不住，只能到处找"忘记密码"
- 🗂️ 账号密码散落在便签、备忘录、浏览器里，乱成一团

**PMWT** 就是为解决这些问题而生的。它帮你把零碎的账号、密码、网址集中管理起来，**防止丢失和遗忘**。

面向所有 **账号密码繁多、网址来往复杂** 的人。
